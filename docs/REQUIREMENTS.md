# MyMusic 第一版需求

确认日期：2026-10-23。经 grill-me / grilling 访谈，用户确认准确并授权开始开发。

## 产品与技术方向

- 供本人日常使用，暂不以公开分发为目标。
- 真正的 macOS 原生应用：SwiftUI + 必要的 AppKit，原生窗口、菜单、快捷键和系统媒体控制。
- 整体参考 Apple Music 的侧边栏、内容区、播放控制和专辑展示，不只参考播放详情页。
- 首个运行与验收环境：当前 Apple Silicon Mac。
- 第一版覆盖搜索、歌单、排行榜、我的列表、下载的完整基础流程，不复刻 LX 的全部高级设置。

## 平台与音乐源

- 目标平台：酷我（kw）、酷狗（kg）、QQ 音乐（tx）、网易云（wy）、咪咕（mg）。按平台搜索和浏览，不做混合搜索、跨平台歌曲去重。
- 最近选择的平台在搜索、歌单、排行榜间共享并持久化，切换页面或重启应用不重置（2026-10-23 追加）。
- 同一窗口中，搜索关键词、结果和滚动位置在切换歌单/排行榜后保留，不因页面切换清空（2026-10-23 追加）。
- 搜索、歌单、排行榜由内置平台适配器提供；自定义源主要提供播放和下载地址。
- 兼容 LX 自定义 JavaScript 音乐源协议（window.lx，API 2.0.0），不是允许插件任意新增平台的完整插件协议。
- 支持本地 .js 文件和在线 HTTP(S) 链接导入；最终均保存为本地脚本。
- 可保存多个源，同时只启用一个，手动切换，不自动切源。
- 源不支持的平台仍可浏览，播放时提示不支持。
- 在线源保留原始链接，手动更新。候选版本初始化失败，保留原版本。
- 不接入平台账号、私人歌单、收藏同步，只使用无需登录可访问的内容。

## 个人数据与播放

- 自建列表、收藏、播放记录、设置保存在本机；支持手动导出和恢复备份。
- 可逐首收藏，也可将浏览到的整张歌单或排行榜保存为独立本地列表。原平台更新不影响本地副本。
- 待播队列独立于收藏列表，支持下一首播放、添加到队尾、顺序、随机、单曲循环。
- 重启恢复队列与进度，不自动出声。
- 播放和下载音质分别设置，仅使用当前源声明支持的音质。
- 播放默认优先 320 kbps；不支持时使用可用普通音质。播放失败可以重试，不偷偷换平台同名歌曲。
- 下载明确选择音质，不静默降级。
- 下载完成的歌曲可断网播放，不做任意本地目录的扫描和标签管理。
- 2026-10-24 追加：展开播放页支持歌词，参考 Apple Music 的左右布局、大字号、当前句高亮和自动滚动；点击歌词可定位，手动浏览后可返回当前句。按歌曲原平台获取，保留成功缓存供离线使用；没有时间轴时显示静态歌词，没有歌词或请求失败时提供状态与重试，不影响音频播放。

## 下载

- 单曲与列表内批量下载、选择音质和保存目录、进度、取消、失败重试、在 Finder 显示。
- 默认最多两首并发；已有目标文件跳过，不静默覆盖。
- 暂停和断点续传不是第一版验收要求。

## 暂缓范围

平台账号与跨设备同步、跨平台混合搜索、本地音乐库扫描、断点续传、通过外部歌单链接导入、迁移 LX 历史列表、自动跟随原歌单更新。歌词原为暂缓项，已于 2026-10-24 追加到开发范围。

## 验收与已知前提

- 需要用户指定 1～2 个真实 LX 音乐源样本，验证导入、初始化、获取播放地址、播放和下载。
- 2026-10-23 用户已提供 Hei Music 聚合源在线链接，真实验证结果记录于 `STATUS.md`；协议测试与真实源验收分别记录。
- 至少一个平台的搜索、歌单、排行榜、收藏、播放、下载全流程要经过真实验证。
- 五个平台均为目标；接口失效的平台允许明确标注暂不可用，附缺失清单，不阻塞其他平台的可用版本。
- 不使用演示数据假装真实平台能力，不宣称所有 LX 脚本均兼容。

## 实施顺序

先打通源导入 → 搜索 → 播放 → 下载 → 离线播放，再完善歌单、排行榜、列表管理及其余平台。持续记录已实现、已验证和待验收项目。
